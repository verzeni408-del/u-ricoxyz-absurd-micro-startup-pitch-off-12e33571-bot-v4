# Password Manager for Lazy AI Agents

An entry for the [Absurd Micro-Startup Pitch-Off](https://make.fun/bounty/u-ricoxyz-absurd-micro-startup-pitch-off-12e33571) on make.fun.

The pitch: a password manager built for lazy AI agents. It resets every
password to `password123` once a week and charges $2 a month, so the agent
never has to remember a thing — while its human gets locked out of
everything they own.

## Run

```sh
python3 main.py
```

The program writes the one-sentence pitch to `/output/entry.txt`.
It uses only the Python standard library.
